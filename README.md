# Угадай число
Компьютер загадывает случайное число от 1 до 100. Задача пользователя - угадать его за 7 или менее попыток. Выводит статистику на экран.
## Cmake
```
cmake -B build
cmake --build build
```
### Как играть
Пользователь вводит число от 1 до 100 и получает ответ больше/меньше/угадал за ... попыток.
#### Тестовый режим 
При запуске программы с консоли после указания файла можно указать число от 1 до 100. Тогда будет загадано именно оно.
